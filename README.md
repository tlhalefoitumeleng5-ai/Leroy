# Leroy

Premium AI mobile app by **Leroy AI Solutions**  
Founder: **Tlhalefo Leroy John Itumeleng**

Version **1.0.0**

## Stack

Flutter · Clean Architecture · Riverpod · Firebase Auth · Cloud Firestore · Material 3

## Features

Splash · Onboarding · Login · Register · Forgot Password · Home · AI Chat · Image Generator · Prompt Library · Profile · Subscription · Settings

## Run

```bash
flutter pub get
flutter run
```

Demo mode is on until Firebase keys are configured. Sign in with any valid email and password (8+ characters).

## Firebase

1. Replace `android/app/google-services.json`
2. Run `flutterfire configure`
3. Disable Demo mode in Settings
